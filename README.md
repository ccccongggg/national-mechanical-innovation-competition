## 🛠 打开方式

- `SLDPRT` / `SLDASM` → SolidWorks（装配体依赖同目录零件，必须整仓下载后再打开）
- `STEP` / `STL` → 通用交换格式，可用于其他 CAD 或 3D 打印切片

## ⚠️ 隐私提醒

`documents/` 含参赛报名与团队审查材料。仓库当前为 Public，转公开 / 分享前应先核查报名表、承诺书中的姓名、联系方式与签名等个人信息，必要时改回 Private。

## ⚠️ LFS 与长路径

CAD、视频、文档等大文件由 **Git LFS** 托管；部分 SolidWorks 导出的 STL 文件名超过 Windows 260 字符限制，克隆时需开启系统长路径（`LongPathsEnabled=1`）或把仓库放到更短路径（如 `D:\uc\`）。
